 1. FUNCIONES PERSONALIZADAS (definidas en ~/.zshrc)
================================================================================

  refresh
    - Recarga la configuracion de zsh sin cerrar terminal
    - Uso: refresh

  settarget <IP> <NOMBRE>
    - Establece un target (IP + nombre maquina) para la barra de polybar
    - Uso: settarget 10.10.10.5 MetaTwo

  cleartarget
    - Limpia el target configurado
    - Uso: cleartarget

  wificonect
    - Abre menu interactivo Python para conectar WiFi (nmcli)
    - Uso: wificonect

  wifiscan
    - Lanza el script de modo monitor para la antena TL-WN722N
    - Opciones: compilar driver, activar monitor, restaurar red
    - Uso: wifiscan

  resnet
    - Restaura servicios de red (NetworkManager, wpa_supplicant)
    - Coloca la interfaz de vuelta en modo managed
    - Uso: resnet

  mkt
    - Crea estructura de directorios para pentesting
    - Crea: nmap/ content/ scripts/ vpn/
    - Uso: mkt

  whichsystem <IP>
    - Detecta sistema operativo por TTL (ping)
    - TTL <= 64 = Linux | TTL 65-128 = Windows
    - Uso: whichsystem 10.10.10.5

  extractPorts <archivo_nmap>
    - Extrae puertos abiertos de un escaneo nmap formato grepable
    - Copia los puertos al portapapeles (xclip)
    - Uso: extractPorts allPorts.gnmap

  infbat
    - Muestra fecha/hora + estado de bateria en verde
    - Uso: infbat

  netaudit
    - Herramienta de auditoria de red (binario Go) - modo interactivo
    - Uso: netaudit

  netscan <comando>
    - Herramienta de auditoria de red - modo comando directo
    - Comandos: discover, scan, banner, sockets, firewall, audit, help
    - Uso: netscan discover 192.168.1.0/24

 5. SCRIPTS DE SERVICIOS (TUI interactivas)
================================================================================

  startftp (alias)
    Gestor FTP con pyftpdlib:
    - Iniciar FTP rapido (anonimo, puerto 2121)
    - Iniciar personalizado (usuario+password+puerto)
    - Conectar a FTP remoto
    - Detener servidor / Ver logs / Estado

  startssh (alias)
    Gestor SSH completo:
    - Activar/Detener servicio SSH
    - Conectar a host remoto
    - Gestionar perfiles guardados (agregar/eliminar)
    - Generar llaves SSH (ed25519)
    - Copiar llave a host remoto

  startfire (alias, requiere sudo)
    Gestor Firewall UFW:
    - Activar/Detener firewall
    - Ver estado y reglas
    - Permitir/Bloquear puertos (TCP/UDP)
    - Denegar IP completa o por puerto
    - Eliminar reglas individuales
    - Reset completo
    - Escaneo de puertos locales en LISTEN

  compartidos (alias, requiere sudo)
    Gestor Samba v6.0:
    - Creacion recomendada (asistida, 1 paso con test automatico)
    - Crear compartido manual (autenticado o guest)
    - Crear/Editar/Eliminar usuarios Samba
    - Gestion: agregar usuario a compartido, toggle lectura/guest
    - Ver estado, conexiones activas
    - Diagnostico y test de conectividad

 7. SCRIPTS DE WIFI/RED
================================================================================

  wifi_conect.py
    Menu interactivo Python para WiFi:
    - Escanear redes disponibles (nmcli)
    - Conectar por SSID + password
    - Desconectar red actual
    - Log de errores autoborrable (5 min)

  tlwn722n-monitormode.sh
    Modo monitor para TL-WN722N:
    - Compilar kernel/driver (rtl8188eus)
    - Activar modo monitor
    - Escaneo de redes con airodump-ng
    - Generar informe de redes en .txt
    - Restaurar procesos de red

  restar_Ser.sh
    Restaurar servicios de red:
    - Detecta interfaces inalambricas
    - Reinicia NetworkManager + wpa_supplicant
    - Restaura interfaz a modo managed
